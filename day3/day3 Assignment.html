hsl stands for Hue,Saturation and lightness. It is a CSS form of coloring or identifying colors. Like the examples above, it can be used in html page to color text.
HUE means the actual colour.
SATURATION means how vivid or dull the color is.
LIGHTNESS means how light or dark the color is.
