JavaScript: var vs let vs const

Understanding the differences between JavaScript variable declarations.

Feature var let const
Scope Function Scope Block Scope Block Scope
Can be Reassigned? ✅ Yes ✅ Yes ❌ No
Can be Redeclared? ✅ Yes ❌ No ❌ No
Hoisted? ✅ Yes (initialized as undefined) ✅ Yes (Temporal Dead Zone) ✅ Yes (Temporal Dead Zone)
Must Assign a Value? ❌ No ❌ No ✅ Yes
Recommended? ❌ Rarely ✅ Yes ✅ Preferred for constants

var Example

var age = 20;
var age = 25;   // Allowed
age = 30;       // Allowed
console.log(age);

let Example

let score = 50;
score = 80;     // Allowed

// let score = 90;
// Error: Cannot redeclare

const Example

const PI = 3.14159;

// PI = 3.14;
// Error: Assignment to constant

console.log(PI);
